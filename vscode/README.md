# git403 for VS Code

A fast, lightweight Git client with a rich commit graph — inside VS Code.

![Commit graph](https://raw.githubusercontent.com/goldtagworks/git403-releases/main/images/1-graph-dark.png)

## Features

- **Commit graph** — open with `git403: Open Commit Graph`. Branch-colored lanes, stage files/hunks/lines, merge, rebase, cherry-pick, conflict resolution.
- **Inline blame** and hover — toggle with `git403: Toggle Inline Blame`.
- **Views** — Branches, Tags, Stashes, Remotes, File History, Line History.
- **CodeLens** and file/line history with diffs.

![Changes](https://raw.githubusercontent.com/goldtagworks/git403-releases/main/images/2-changes-dark.png)

## Requirements

- `git` installed on your system.
- Platforms: macOS (Apple Silicon), Windows x64.

## Why

I tried several Git clients — each was either buggy for me, unfamiliar, required a company-purchased license for work use, or kept core features like the commit graph behind a paid plan and a sign-in. git403 aims for a full-featured client with a rich commit graph in a small, fast app. **Completely free — no paid plan, no feature gates, no account or sign-in. It's just a Git client.**
